## Что делает

Перетащите в окно один или несколько Excel-файлов, и программа сама:

1. определит формат каждого файла по названиям колонок;
2. объединит файлы одного формата в один;
3. разложит товары по моделям, посчитает коробы и пары;
4. сохранит готовый файл рядом с исходным: **`имя_файла_sortirovka.xlsx`**.

Файлы разных форматов можно загружать вместе. Каждый формат соберётся в свой общий файл.

Все данные обрабатываются на вашем компьютере и никуда не отправляются.

---

## Поддерживаемые форматы

### 1. Выгрузка по коробам

Каждая пара обуви отдельной строкой, у пар в одном коробе одинаковый код SSCC.

| Обязательные колонки |
|---|
| `Модель` · `Код упаковки SSCC` · `Размер` |

**Что получится в файле:**

- **Сводка** — по каждой модели число коробов и пар, разбивка по размерам, итого. Если файлов несколько, внизу список файлов с числом пар в каждом.
- **Лист на каждую модель** — все её строки, отсортированные по коробу и размеру.

**Проверки:** программа предупредит, если в коробе больше 8 пар или в одном коробе смешаны разные модели. Неполные короба (меньше 8 пар) считаются как есть, а их число показывается в карточке результата.

### 2. График поставок

Одна строка на модель в поставке: уже готовое число коробов и пар.

| Обязательные колонки | Используются, если есть |
|---|---|
| `Модель` · `Кол-во коробов` · `Кол-во пар` | `Дата` · `Время` · `Кол-во пар общее` · `Кол-во коробов общее` · `Объем поставки, куб` · `Артикул Кари` · `Артикул короба` · `ШК короба` · `Цена закупки` · `Примеч` |

**Что получится в файле:**

- **Сводка** — по каждой модели артикул, коробы, пары, число поставок и пары по каждой поставке.
- **Поставки** — каждая поставка: пары и коробы по шапке файла рядом с суммой по моделям, плюс список замечаний.
- **Лист на каждую модель** — все поставки этой модели по датам.

**Проверки:** программа предупредит, если дата в названии файла не совпадает с датой внутри (берётся дата из файла), если итоги в шапке не сходятся с суммой по моделям, если пар не равно коробам × 8 или если у одной модели несколько артикулов или цен.

Город поставки берётся из названия файла до первого символа `_`, например `Москва_11_08_2026.xlsx`.

## Как пользоваться

1. Запустите `Sortirovka.exe`.
2. Перетащите файлы `.xlsx` в окно или нажмите на зону и выберите их в диалоге.
3. Готовый файл появится в той же папке. В окне будут его имя, статистика и кнопки **Открыть** и **В папке**.

> Закройте результат в Excel, прежде чем запускать обработку повторно. Если файл открыт, Windows не даст его перезаписать.

**Имя результата:**

| Загружено | Результат |
|---|---|
| `MC_185107.xlsx` | `MC_185107_sortirovka.xlsx` |
| `MC_185107.xlsx`, `MC_185108.xlsx` | `MC_185107_MC_185108_sortirovka.xlsx` |
| много файлов (длинное имя) | `первый_файл_plusN_sortirovka.xlsx` |

## Запуск из исходников

Нужен Python 3.11 или новее с [python.org](https://www.python.org/downloads/) (в нём уже есть tkinter).

```bash
pip install -r requirements.txt
python app.py
```

## Сборка exe

Собирать нужно на Windows. Запустите двойным кликом **`build.bat`** или выполните вручную:

```bash
python -m pip install -r requirements.txt
python -m PyInstaller --noconsole --onefile --collect-all tkinterdnd2 --name Sortirovka app.py
```

Готовый файл появится в `dist\Sortirovka.exe`.

> Windows может показать окно SmartScreen, потому что exe не подписан. Нужно нажать **Подробнее → Выполнить в любом случае**. Отправлять файл удобнее в zip-архиве.

## Структура проекта

```
├── app.py               # окно приложения (tkinter, тёмная тема, drag & drop)
├── sortirovka_core.py   # логика: чтение Excel, определение формата, сборка результата
├── requirements.txt     # openpyxl, tkinterdnd2, pyinstaller
└── build.bat            # сборка exe одним кликом
```

Логика сортировки лежит отдельно от окна, поэтому ею можно пользоваться и без интерфейса:

```python
import sortirovka_core as core

results = core.process_files(["MC_185107.xlsx", "MC_185108.xlsx"])
for r in results:
    print(r["output"], r["pairs"], r["warnings"])
```

`process_files` возвращает список результатов, по одному на каждый формат. В словаре: `kind`, `files`, `output`, `models`, `boxes`, `pairs`, `warnings`.

## Технологии

- **Python** и **tkinter**: окно, свой тёмный дизайн без сторонних тем.
- **openpyxl**: чтение и запись Excel. Pandas не используется, поэтому exe получается небольшим.
- **tkinterdnd2**: перетаскивание файлов в окно (если библиотека не загрузилась, файл выбирается по клику).
- **PyInstaller**: упаковка в один exe.

## Ограничения

- Поддерживается только формат `.xlsx` (не `.xls`).
- Все файлы одного формата должны иметь одинаковые колонки, иначе будет ошибка с названием проблемного файла.
- Сам exe работает только на Windows.
